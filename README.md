# Spiral

An interactive, browser-based story relationship diagram served by a tiny Python server. It combines Cartesian axes, Maurice Clochard intimacy circles, movable character points, a golden-ratio spiral, and configurable multi-arm Fibonacci geometry.

## Run

```bash
python app.py
```

Open <http://127.0.0.1:8000>. No third-party Python dependencies are required.

## Features

- Drag characters directly on the canvas and edit their labels, colors, and sizes.
- Add, remove, resize, and style concentric intimacy circles.
- Toggle the graduated grid, golden-ratio curve, Fibonacci bloom, and construction geometry.
- Transform the Fibonacci system from three to twelve rotational arms.
- Zoom, reset, persist locally, and export the canvas as a PNG.
